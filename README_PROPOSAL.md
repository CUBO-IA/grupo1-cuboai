# Propuesta independiente para Wiener Kingdom

La carpeta se copia al repositorio existente en una rama separada. Esta propuesta **solo añade archivos nuevos**, sin reemplazar templates, modelos ni migraciones actuales. Ver `docs/proposal/BRANCHING_AND_REVIEW.md`.

**Para equipo:** `docs/proposal/MASTER_BUSINESS_ATLAS.md` y `PROJECT_WEBSITE_REQUIREMENTS.md`. **Para diseño:** `BRAND_SYSTEM.md` y `proposals/wiener-kingdom-next/index.html`. **Para técnica:** `REPOSITORY_AUDIT.md`, `ARCHITECTURE_TRANSITION.md` y `AI_HANDOFF.md`.
